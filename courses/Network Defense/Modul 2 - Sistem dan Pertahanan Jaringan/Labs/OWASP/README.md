## Background / Scenario

The Open Web Application Security Project (OWASP) is a nonprofit organization dedicated to improving web application security. OWASP publishes the **OWASP Top 10**, a widely recognized report that identifies the most critical web application security risks faced by organizations worldwide. The report is updated periodically, with the latest major release published in 2021.

The primary objective of the OWASP Top 10 is to:
- increase awareness of web application security risks
- help organizations strengthen their secure development practices
- support the implementation of effective security controls
- reduce and prevent application security vulnerabilities

In addition to the OWASP Top 10 report, OWASP also maintains community-driven security resources that include:
- attack techniques
- vulnerability references
- security best practices
- risk mitigation guidance

The OWASP Community Pages provide publicly contributed information related to emerging threats, vulnerabilities, and security research from cybersecurity professionals worldwide.

## Lab Overview

In this lab, the focus is on exploring:
- the OWASP Top 10 (2021)

- security vulnerabilities reported by the OWASP community

The lab is designed to improve understanding of modern web application security threats and the importance of secure coding, risk management, and layered security practices.
